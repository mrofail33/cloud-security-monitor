# Screenshots and Examples

Use this folder for screenshots from your own controlled AWS lab only.

Recommended screenshots to capture:

1. CloudTrail trail enabled in your lab account.
2. CloudTrail event history showing one safe test event, such as an IAM user creation in your lab.
3. Exported CloudTrail JSON file or S3 log location from your lab.
4. Terminal output from running this monitor against the safe sample data.
5. Terminal output from running this monitor against logs exported from your own lab.

Do not include credentials, account IDs you do not want public, access keys, private IPs, or screenshots from third-party AWS environments.
